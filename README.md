# MCP Hub 데모

[MCP Hub](https://github.com/syndgo-byte/Main_MCP_Hub)의 동작 영상입니다. 노드 캔버스에서 시작해 3D 관제판(야간, 주간), 보안 진단까지 이어집니다.

마지막 업데이트: 2026-09-29 18:17

### [demo.mp4 다운로드해서 보기](demo.mp4)

GitHub는 README에 직접 붙인 `<video>` 태그나 raw 링크는 자동 재생으로 인식하지 않습니다. 브라우저에서 README 편집 화면에 파일을 직접 드래그해서 올렸을 때 생기는 `user-attachments` 링크만 인라인 재생이 되는데, 이건 웹 UI에서 사람이 직접 올려야만 생기는 링크라 API/코드로는 만들 수 없습니다. 위 링크를 누르면 GitHub가 다운로드 후 재생 안내를 보여줍니다.

## 영상 순서

| 구간 | 내용 |
| --- | --- |
| 오프닝 | MCP Hub 소개 카드, 서비스 연결 · 라이선스 · 3D 관제 · 보안 진단 키워드 |
| 노드 캔버스 | 서비스 노드와 기능 포트, 자동 연결선, 노드 선택과 매니페스트/라이선스 |
| 3D 관제판 · 야간 | 달과 별, 은하수가 흐르는 야간 도시 와이드샷에서 도시로 줌인, 관제 현황 숫자로 장애 목록 열기 |
| 하늘섬 · 야간 | 허브 위 섬, 흰 가로등, UFO(심각)와 소방 비행기(에러)의 타원 비행 살수 |
| 지상 출동 | 심각 건물 위 헬기 살수, 불꽃과 연기, 구역 경보 |
| 드론 | 구역 사이 연결을 화물 드론이 오가는 모습을 따라가며 촬영 |
| 3D 관제판 · 주간 | 큰 줌아웃 전경에서 호수와 성당풍 허브가 있는 낮의 도시로 |
| 하늘 | 파스텔 무지개와 떨어지는 반짝이, 흘러가는 구름 |
| 하늘섬 · 주간 | 소방 비행기가 섬 위를 타원으로 도는 모습 |
| 허브 · 드론 | 빨간 지붕 허브와 첨탑들, 화물 드론, 전체 도시 줌아웃 |
| 전경 줌아웃 · 야간 | 건물에서 물러나며 달빛 아래 도시 전체가 드러나는 마무리 |
| 보안 진단 | 서비스별 취약점 집계, 항목 상세와 AI 수정안 diff |

## 볼거리

- 야간 와이드샷에서 달, 별, 은하수까지 보이는 하늘 배경과 주간 와이드샷의 무지개 줌아웃
- 장애 등급마다 다른 출동 연출: 경고는 소방차와 소방관, 에러는 소방 비행기, 심각은 헬기나 UFO
- 의존 모듈이 멈추면 해당 구역 태그가 깜박이고 바닥에 경보 파문이 퍼짐
- 다크 모드는 창문 불빛과 블룸 효과, 화이트 모드는 그림자와 반사 호수
- 모든 텍스처는 코드로 직접 그림 (외부 이미지 없음)

기술: React, TypeScript, three.js, @react-three/fiber, drei, postprocessing, @xyflow/react / FastAPI, SQLAlchemy
