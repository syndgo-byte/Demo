## MCP Hub

### [MCP_HUB_DEMO.mp4 다운로드해서 보기](MCP_HUB_DEMO.mp4)

노드 캔버스와 계통도에서 시작해 3D 관제판(야간, 주간)을 한 바퀴 돌아보고, 관리 서비스의 보안 진단 · 리눅스 커널 점검, 민원 처리, 공지·알림까지 이어집니다.

| 구간 | 내용 |
| --- | --- |
| 오프닝 | MCP Hub 소개 카드, 서비스 연결 · 계통도 · 3D 관제 · 관리 서비스 키워드 |
| 01 노드 캔버스 | 서비스 노드와 기능 포트, 자동 연결선, 노드 선택과 매니페스트/라이선스 |
| 02 계통도 | 라우터 · 방화벽 · L4 · 스위치 아래 서버별 서비스 배치, 부하 기준 서버 대수 산정 |
| 03 3D 관제판 · 야간 | 도시를 스윽 한 바퀴 돈 뒤 크게 물러나며 달과 은하수 아래 전경, 줌아웃하는 동안 화면 UI(관제 현황 · 최근 이벤트 · 범례 · 모드 · 탭) 소개 |
| 03-1 하늘섬 테스트 모듈 | `temp_demo`·`temp_warn`·`temp_error`·`temp_crit`의 상태와 장애별 출동을 가까이에서 확인 |
| 04 3D 관제판 · 주간 | 낮의 도시를 한 바퀴 돈 뒤 파스텔 무지개가 보이는 큰 줌아웃, 같은 방식으로 UI 소개 |
| 05 관리 서비스 | 서비스별 보안 진단 집계, 복사본 코드의 오프라인 진단 결과와 검증 승인 흐름 안내, 목록/상세 폭 조절, 리눅스 커널 상태와 권고안 확인 |
| 06 민원 관리 | 시연 민원 목록·처리 상태·상세 내용 확인 |
| 07 공지·알림 | 서비스 공지·알림 목록과 상세 내용 확인 |

볼거리

- 현재 허브에 등록된 서비스 25개를 기준으로 촬영했습니다. 하늘섬에 테스트 모듈 4개, 지상 구역에 테스트 웹 서비스 3개가 표시됩니다
- 야간 와이드샷에서 달, 별, 은하수까지 보이는 하늘 배경과 주간 와이드샷의 무지개 줌아웃
- 장애 등급마다 다른 출동 연출: 경고는 소방차와 소방관, 에러는 소방 비행기, 심각은 헬기나 UFO
- 의존 모듈이 멈추면 해당 구역 태그가 깜박이고 바닥에 경보 파문이 퍼짐
- 다크 모드는 창문 불빛과 블룸 효과, 화이트 모드는 그림자와 반사 호수
- 반복되는 경고는 하나로 묶고 10회면 high, 30회면 critical 로 올려 알림
- 모든 텍스처는 코드로 직접 그림 (외부 이미지 없음)

기술: React, TypeScript, three.js, @react-three/fiber, drei, postprocessing, @xyflow/react / FastAPI, SQLAlchemy

## EMS v3

### [EMSv3_DEMO.mp4 다운로드해서 보기](EMSv3_DEMO.mp4)

통신 · 전기 공사 설계 솔루션입니다. 표준품셈 기준자료를 올리고, 설계 마법사로 물량과 공사비를 산출해 엑셀 설계서로 내보낸 뒤 준공까지 관리합니다. 폐쇄망 · 인터넷 두 에디션을 한 코드베이스로 운영합니다.

| 구간 | 내용 |
| --- | --- |
| 오프닝 | EMS v3 소개 카드, 공사 설계 · 물량 산출 · 엑셀 설계서 · 준공 관리 키워드 |
| 00 시작 | 포털 첫 화면과 로그인 (비밀번호는 브라우저에서 암호화) |
| 01 대시보드 | 설계 4단계 프로세스, 연간 공정 타임라인과 공기지연(D+일수) 표시, 설계서 목록 |
| 02 기준자료 등록 | 표준품셈 PDF · 엑셀 업로드와 공종 · 단가 자동 추출, 연도별 품셈 라이브러리 |
| 03 설계 마법사 | 기본정보 입력과 실시간 공사비 집계, 품셈 & 물량산출, 제비율 확인, 시설 도면 스튜디오 (2D 도면을 3D로 올려 회전) |
| 04 설계서 조회 | 연도 · 부서 · 담당자별 조회, 표/카드 뷰 전환 |
| 04-1 설계 변경 비교 | 변경 전 · 후 버전을 골라 당초 · 변경 총공사비와 증감액, 공종별 수량 · 금액 증감 대비표, 설계변경 사유서 문안 자동 작성 |
| 05 준공 관리 | 설계비 대비 준공비 실적 비교와 준공 처리 |
| 06 관리 · 결제 | 가입 승인 · 권한 · 허용 PC 좌석 관리, 월 구독 · 크레딧 충전 (체험판은 모의 결제) |
| 07 민원 · 메시지 | 시연 문의의 접수·답변 완료 상태, 질문과 담당자 답변 확인 |

설계 변경 비교 구간의 변경 전 · 후 프로젝트(DEMO-2026-UPDATE-v1/v2)는 녹화용 복사본 DB에 넣은 시연 데이터입니다.

기술: FastAPI, Jinja2, SQLite, three.js
